    Accuracy & trust

    Read-only by design. Private by default.

    Two principles are wired into the architecture, not bolted on as settings you have to find.

    It runs entirely on your machine

    The MCP server and demo talk to Trade Republic directly from your computer. There is no third-party server, no proxy, no telemetry. The session lives at ~/.trade-republic-mcp with 0600 permissions (owner-only).

    Nothing leaves your device

    Every action is read-only

    The tools expose portfolio, cash and timeline reads, and nothing else. No order, payout or savings-plan endpoint is wired in, so an agent physically cannot move your money, no matter what it's asked.

    Trades, transfers & payouts are not exposed
    Get started

    Connected in five steps.

    Clone, register, verify, open Claude, then log in through the browser it opens. Once. Every line below is one-click copy.

    # 1 · clone & install
    git clone https://github.com/jetaix/trade-republic-platform
    cd trade-republic-platform
    pnpm install
    pnpm --filter @trade-republic/api exec playwright install chromium
    # 2 · register with Claude (run from the repo root)
    claude mcp add trade-republic -- node "$(pwd)/packages/mcp/server.mjs"
    # 3 · check it worked, should list "trade-republic"
    claude mcp list
    # 4 · open Claude
    claude

    5 · Connect & use

    1. In Claude, paste and a browser opens for your phone, PIN and 2FA (never typed into the chat).
    2. The page shows ✅ Connected. The session is saved locally and auto-refreshed, so you only do this once.
